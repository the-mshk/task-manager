# Требования к проекту

Цель: разработать приложение для управления личными задачами.

Пользователь: человек, которому нужно вести список дел.

Функциональные требования:
1. Добавление задачи с названием.
2. Просмотр списка задач.
3. Отметка задачи как выполненной.
4. Удаление задачи.
5. Сохранение задач между запусками.

Нефункциональные требования:
1. Консольный интерфейс.
2. Хранение исходного кода в Git.
3. Документация в формате Markdown.
