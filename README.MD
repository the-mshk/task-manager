# Менеджер задач

Учебный проект по дисциплине «Инструменты Девопс».

Приложение предназначено для управления личными задачами.

Планируемые возможности:
- добавление задач;
- просмотр списка задач;
- отметка выполненных задач;
- удаление задач.

Технологии: Python, Git, GitHub.

## Структура проекта
- src/ — исходный код;
- docs/ — документация;
- TASKS.md — список задач проекта.

## Запуск
python src/main.py
